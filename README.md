# M.A-Paint-House-

M.A Paint House Account Manager — a React + Vite + Tailwind CSS business and customer accounting app backed by Firebase Authentication and Firestore.

## Features

- Customer accounts, ledgers, invoices, and receipts
- Product families, products, and price management
- Bulk product import from Markdown tables or CSV
- Expense tracking and reports
- PDF invoices, receipts, statements, and reports
- Firebase Authentication with Firestore data storage

## Tech Stack

- React 19 + TypeScript
- Vite 8
- Tailwind CSS v4
- Firebase (Authentication + Firestore + Analytics)

## Getting Started

```bash
pnpm install
pnpm dev
```

The development server runs on `http://localhost:8443`.

## Build

```bash
pnpm build
```
